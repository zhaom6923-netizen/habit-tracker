# 今日习惯

一个可以直接在浏览器使用，也可以安装到手机主屏幕的习惯打卡应用。

## 本地打开

直接打开 `index.html` 即可。习惯和打卡数据保存在当前浏览器，本地打开不需要服务器。

## 手机安装

发布到 HTTPS 地址后：

- iPhone：用 Safari 打开，点击“分享”并选择“添加到主屏幕”。
- Android：用 Chrome 打开，点击浏览器菜单中的“添加到主屏幕”或“安装应用”。

安装后可以像普通应用一样从主屏幕启动，并在离线状态下继续使用。

## GitHub Pages 发布

仓库已包含 GitHub Pages 自动部署配置。将项目推送到 GitHub 仓库的 `main` 或 `master` 分支后，在仓库的 `Settings > Pages` 中把发布来源设为 `GitHub Actions`。后续每次推送都会自动更新公开链接。

每位访问者使用自己的浏览器数据，习惯记录不会在用户之间同步。
